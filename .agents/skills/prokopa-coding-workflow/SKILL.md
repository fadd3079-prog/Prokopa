# Prokopa Coding Workflow

Use this skill at the start of Prokopa coding, review, debugging, or planning work when the task spans more than one concern.

- Treat `PRD.md` as the product authority.
- Treat `AGENTS.md` as the project execution authority.
- Keep Anti-Slop mandatory. Load `antislop` plus the matching Anti-Slop subskill for UI, copy, people, mobile layout, or code comments work.
- Load Flutter skills for Flutter-specific UI, lifecycle, layout, widget, navigation, or platform behavior.
- Load Dart skills for Dart-specific language, analysis, package, path, or unit-test work.
- Load persistence and data-portability skills for local database, backup, export, import, or restore work.
- Load testing skills for unit, widget, integration, golden, accessibility, or TDD work.
- Load debugging skills when investigating failures, runtime errors, layout exceptions, flaky tests, or performance regressions.
- Load accessibility skills for semantics, contrast, keyboard, text scaling, reduced motion, or touch target work.
- Load security and privacy skills for app lock, sensitive local data, backup files, destructive actions, or notification privacy.
- Load context-engineering or repo-context-packaging only when repository context is large or needs handoff.
- Do not load unrelated skills for React, Vue, Kubernetes, Terraform, backend frameworks, cloud infrastructure, or technologies outside the current Prokopa task.
- Skills are guidance only. Do not add dependencies, change architecture, or introduce a stack unless `PRD.md`, `AGENTS.md`, and the current task justify it.
